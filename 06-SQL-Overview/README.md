# SQL Overview

`01-SQL-Overview.ipynb` practices cleaning, joining, and summarizing NOAA weather data from `bigquery-public-data.noaa_gsod`. Sections A to G are the core exercise. Section H is an optional challenge that brings in unions, wildcard tables, views, sampling, and `QUALIFY`.

Run it in any of the notebook options from class 3 (see `03-Data-Warehousing/README.md`). In free Colab, run the setup cell near the top first so your queries bill to your own project.

Every question has a SOLUTION cell and the harder ones have a HINT cell, each with a commented-out `disp(...)` line. Uncomment it and run the cell to load the hint or solution from `docs/hints/`.
