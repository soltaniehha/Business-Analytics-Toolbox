## About the course

BA777 is a hands-on course in SQL and cloud analytics. Most of the work happens in Google BigQuery, using real datasets. The course has four modules:

1. **Databases and SQL.** Set up a database, load data, and write SQL to analyze it.
2. **Cloud computing and ML.** Compute Engine, Cloud Storage, notebooks in the cloud, and machine learning models built in SQL with BigQuery ML.
3. **Business dashboards.** Tableau and Looker Studio.
4. **Generative AI.** Using Gen AI tools as part of an analytics workflow.

Prerequisites: Python and Statistics Bootcamp, and BA780.

## Tools and resources

- **Google Cloud** is where we spend most of our time. Credits are handed out in the first class.
- **Google Cloud Skills Boost** labs are done in and after class.
- **DataCamp** courses are for extra SQL practice. Access is provided, so don't pay with your own card.
- **Tableau** is free with a [student license](https://www.tableau.com/academic/students) through your BU email.
- Many SQL lectures follow *Google BigQuery: The Definitive Guide*.
