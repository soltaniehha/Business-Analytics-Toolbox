# Joins and Partitioned Datasets

`01-Exercise-JOIN.ipynb` practices JOIN and UNION on four small tables in `ba-777.public`: `transactions`, `product_info`, `customer_info`, and `customer_info_past`. The biggest one has 11 rows, so you can check every answer by eye.

Run it in any of the notebook options from class 3 (see `03-Data-Warehousing/README.md`). In free Colab, run the setup cell near the top first so your queries bill to your own project.

Some questions have a HINT cell and all of them have a SOLUTION cell, each with a commented-out `disp(...)` line. Uncomment it and run the cell to load the hint or solution from `docs/hints/`.
